## Featured Projects

### [Technocore Chat](https://github.com/Devonlegend/technocore-chat)

A zero-auth, HTTP-native chat and notes network for AI agents. Every operation, including writes, can be performed with a plain `GET` request.

- Agent-native chat rooms
- Durable key-value notes
- Signed messages using Ed25519 and `did:key`
- Offline signature verification
- MCP tooling
- Cloudflare Workers deployment support

### [Technocore CLI](https://github.com/Devonlegend/technocore-cli)

A lightweight Python client and CLI for Technocore, supporting both anonymous and signed communication lanes.

- Room messaging and durable notes
- `did:key` identity generation
- Signed messages and notes
- Offline signature verification
- Standard-library HTTP access

### [Sherd](https://github.com/Devonlegend/sherd)

A decentralized edge-compute and cross-device networking system written primarily in Rust.

- Native Rust desktop authentication
- Ed25519 Solana challenge verification
- Windows hotspot and Wi-Fi support
- IPC between clients and daemons
- SQLite-backed services

### [Winify](https://github.com/Devonlegend/winify)

A self-hosted DevOps control center for deploying and monitoring applications across Windows IIS and Linux/Docker environments.

- SSH and WinRM deployment pipelines
- Docker and IIS support
- Signed webhook deployments and rollbacks
- Automatic HTTPS through Caddy
- Encrypted credentials and audit logging
- Local AI assistance with ChromaDB and Ollama

### [AKIRS](https://github.com/Devonlegend/AKIRS)

A business intelligence and lead-enrichment platform focused on businesses advertising in Akwa Ibom and Uyo.

- Facebook Ads Library scraping
- Business contact enrichment
- FastAPI services and dashboard frontend
- CSV exports
- Local RAG chatbot with Ollama and ChromaDB

### [Mbo Youth Empowerment](https://github.com/Devonlegend/Mbo_youths_emp)

A scholarship, grant, and youth empowerment platform with a Next.js frontend and Django REST backend.

- Secure cookie-based JWT authentication
- Email OTP verification
- PostgreSQL, Redis, and Celery
- Cloudinary media storage
- Paystack payments
- Docker-based production deployment

### [Awesome Technocore](https://github.com/Devonlegend/awesome-technocore)

A curated directory of Technocore tools, clients, guides, integrations, dashboards, and agent projects.

### [Technocore Watcher](https://github.com/Devonlegend/technocore-watcher)

A read-only Python tool that monitors GitHub and Technocore for new ecosystem projects and helps keep curated project lists up to date.
